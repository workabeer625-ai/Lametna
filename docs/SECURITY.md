# الأمان والخصوصية · Security

## 1. نموذج التهديد

نفترض أن المهاجم يملك التطبيق مفكّكًا، والمفتاح العام (anon)، وقدرة على استدعاء أي نقطة
نهاية بأي معاملات. البناء كله قائم على هذا الافتراض.

| التهديد | الدفاع |
|---------|--------|
| تزوير النقاط | لا سياسة كتابة على `scores`؛ ومشغّل يحمي `profiles.total_points` |
| قراءة أدوار المافيا | RLS تقصر `mafia_roles` على صفّ اللاعب نفسه |
| قراءة كلمة الكذاب | `rounds.secret_data` مسحوب الصلاحية على مستوى العمود |
| قراءة إجابات الأسئلة | `questions.answer` و `alt_answers` مسحوبتا الصلاحية |
| تخمين كلمة مرور الغرفة | bcrypt + العمود غير مقروء للعميل + حدّ معدّل |
| تمديد وقت الجولة | `ends_at` على الخادم، و`tick-rounds` يحسم بلا العميل |
| الإغراق بالرسائل | حدّ معدّل + حدّ طول 300 حرف + قاموس ألفاظ |
| رفع صلاحية إلى مشرف | `role` غير قابل للتعديل من العميل؛ يتغيّر بـ SQL فقط |
| انتحال هوية | البريد يتحقق عبر Supabase Auth؛ الضيوف موسومون بوضوح |
| تسريب المفاتيح | لا `service_role` في التطبيق ولا في لوحة التحكم؛ الأسرار في Edge Secrets |

## 2. المصادقة

- **بريد + كلمة مرور** عبر Supabase Auth (تجزئة وتدوير الرموز من المنصّة).
- **ضيف** = مستخدم مجهول (anonymous sign-in) بلا بريد ولا هاتف، صلاحيته 30 يومًا.
- `flutter_secure_storage` للبيانات الحسّاسة محليًا؛ رمز الجلسة يديره Supabase نفسه.
- **لا يوجد مفتاح سرّي في التطبيق.** فقط `SUPABASE_URL` و anon key عبر `--dart-define`،
  وكلاهما عام بطبيعته ومحميّ بـ RLS.

## 3. الترخيص

ثلاث طبقات متتابعة:

```
1) هل الطلب مصادق؟           auth.uid() is not null
2) هل يحق له هذا الصف؟        سياسات RLS
3) هل يحق له هذا الفعل؟       فحوص داخل الدالة: is_room_host / is_admin / is_alive …
```

الواجهة تخفي الأزرار التي لا تخصّك — لكن هذا **راحة بصرية فقط**، والفحص الحقيقي في
قاعدة البيانات دائمًا.

## 4. سلطة الخادم

| القرار | المكان |
|--------|--------|
| توزيع أدوار المافيا | `start_game()` |
| احتساب كل نقطة | `resolve_round()` → `_award()` |
| فرز الأصوات | `resolve_round()` |
| من يموت ومن ينجو | `resolve_round()` |
| بداية الجولة ونهايتها | `_begin_round()` + `rounds.ends_at` |
| منح الشارات | `_evaluate_achievements()` |

الدوال الداخلية (`_award`, `_begin_round`, `_finish_session`, `_mafia_check_win`, …)
مسحوبة الصلاحية عن `anon` و `authenticated` — غير قابلة للاستدعاء من الخارج أصلًا.

## 5. الإشراف على المحتوى

| الطبقة | التفصيل |
|--------|---------|
| حدّ الطول | 1–300 حرفًا للرسالة، 500 لتفاصيل البلاغ |
| منع الروابط | `contains_link()` يغطي `http(s)`, `www.`, النطاقات المجرّدة، `t.me` |
| قاموس الألفاظ | جدول `banned_words` قابل للتحديث بلا إصدار تطبيق جديد |
| التطبيع | `normalize_ar()` يمنع التحايل بالتشكيل والتطويل |
| حدّ المعدّل | رسالة كل ثانيتين تقريبًا؛ حدّ لعدد الغرف لكل مستخدم |
| الكتم | المضيف يكتم داخل غرفته |
| الطرد والحظر | حظر غرفة أو حظر عام، مؤقّت أو دائم |
| الحجب الشخصي | `user_blocks` — لا أرى محتواه ولا يراني |
| البلاغات | 10 أسباب، مع منع التكرار وتتبّع الحالة |
| سجل العمليات | كل فعل إشرافي في `audit_logs` مع الفاعل والوقت |

التصفية موجودة في العميل أيضًا (`content_filter.dart`) — لكن كرسالة خطأ فورية فقط،
والخادم يعيد الفحص دائمًا.

## 6. الخصوصية

**ما لا نجمعه إطلاقًا:**
الاسم الحقيقي · رقم الهاتف · الموقع الجغرافي · جهات الاتصال · الصور · الصوت · الفيديو ·
معرّفات الإعلانات · أي تتبّع لطرف ثالث.

**ما نجمعه:** الاسم المستعار، مفتاح صورة رمزية جاهزة، بريد إلكتروني (للحسابات المسجّلة فقط)،
دولة **اختيارية**، وإحصاءات اللعب.

**الصلاحيات على أندرويد:** `INTERNET` و `ACCESS_NETWORK_STATE`. لا غير.
والمانيفست يزيل صراحةً `CAMERA` و `RECORD_AUDIO` لو أدخلتهما مكتبة تابعة:

```xml
<uses-permission android:name="android.permission.CAMERA" tools:node="remove" />
<uses-permission android:name="android.permission.RECORD_AUDIO" tools:node="remove" />
```

**حذف الحساب** (`delete_my_account`) يعمل فعلًا: مغادرة الغرف، حذف ناعم للملف الشخصي،
إخفاء الاسم والصورة والدولة، وحذف الرسائل الشخصية. سجلات النقاط تبقى **مجهولة الهوية**
حتى لا ينهار الترتيب التاريخي.

**الاحتفاظ بالبيانات:** الرسائل 7 أيام · الغرف المغلقة 24 ساعة · جلسات الضيوف 30 يومًا ·
سجل العمليات 90 يومًا.

## 7. أمان البناء

- `.gitignore` يستثني `env.json`, `android/key.properties`, `*.jks`, `*.keystore`.
- التوقيع يقرأ من `key.properties` خارج المستودع؛ وإن غاب الملف يُبنى بتوقيع debug بدل الانهيار.
- R8 مفعّل مع `isMinifyEnabled` و `isShrinkResources` في الإصدار.
- لا مفاتيح مكتوبة في الكود: `Env` يقرأ من `--dart-define` فقط، والبناء يفشل مبكرًا إن لم تُضبط.

## 8. قائمة تحقّق قبل الإطلاق

- [ ] `supabase db push` نجح، و RLS ظاهر مفعّلًا على كل الجداول في اللوحة.
- [ ] حاول قراءة `rooms.password_hash` و `rounds.secret_data` من REST — يجب أن تفشل.
- [ ] حاول `insert` في `scores` من حساب عادي — يجب أن يفشل.
- [ ] `tick-rounds` و `cleanup-rooms` مجدولتان وتعملان (راجع Function Logs).
- [ ] `CLEANUP_CRON_SECRET` مضبوط، واستدعاء الدالة بلا الترويسة يعيد 401.
- [ ] لوحة التحكم منشورة، ولا تحوي إلا anon key، ولا يدخلها إلا حساب `admin/moderator`.
- [ ] تأكيد البريد مفعّل، وعناوين إعادة التوجيه مضبوطة.
- [ ] `flutter build apk --release` ثم فحص المانيفست: لا صلاحيات وسائط.
- [ ] سياسة الخصوصية والشروط ظاهرتان داخل التطبيق ومربوطتان في صفحة المتجر.
